Spreadsheet Information
                Some of the endpoints have alternative formats that are easier to import into your google spreadsheets if you are having trouble with JSON data.
                You only need to copy the provided the links below to your spreadsheets formula bar and it should work.
If you are having any trouble you can always ask for help on our discords #help channel. 
Competition Information V2
                - Once you have copied the formula below into your spreadsheet you need to change this number 
id=27764
 to match your competitions ID to fetch data from it 
                - You can change what skill/boss/custom category is being used by adding 
&skill=prayer
 at the end of the URL 
                - And view the competition standings as they were for example after day one by adding this 
&snapshot=1day
 to the URL
                - If you want the table to return the competition standings for teams change the parameter 
&format=table
 to 
&format=tableTeams
                - You can use 
&format=csv
 to return the data in a CSV format

Recent 200ms
GET
                This endpoint attempts to retrieve a list of the 25 most recent 200ms in a skill
                Example: 
https://templeosrs.com/api/recent_200ms.php?skill=8
Parameters
Parameter
Documentation
skill
Skill parameter enumeration, goes in order of which the skills are shown on the hiscores page
0 = Overall ... 24 = EHP (119 = Sailing)
Attributes
Attribute
Documentation
data/Username
The RSN of the player who achieved a 200m
data/Date
The timestamp of the data point of which the player achieved a 200m
data/Skill
Skill parameter enumeration, goes in order of which the skills are shown on the hiscores page
0 = Overall ... 24 = EHP (119 = Sailing)
data/Country
The country of the player that has been set via the TempleOSRS Discord server
data/Game Mode
Enumeration for game mode; 0 = Main, 1 = IM, 2 = UIM, 3 = HCIM
data/Twitter
The player's Twitter profile link (donation perk)
data/Rank
The player's rank for the skill on the official hiscores

This field is mandatory for any 6h records after August 21st 2021

Player Information
GET
                This endpoint attempts to give you any valuable information from the player's overview page.
                Example: 
https://templeosrs.com/api/player_info.php?player=Mikael
Parameters
Parameter
Documentation
player
The current RSN of the player you are trying to look up
dateformat
Format of the dates returned. Currently only supported value is "unix" for unix timestamp.
cloginfo
The response will include additional collection log related information.
formattedrsn
The response will include the RSN how it is in-game with proper capitalization and special characters.
Attributes
Attribute
Documentation
Username
The current RSN of the player
player_name_with_capitalization
The RSN of the participant, with special symbols and capitalization it has ingame.
 Note: Only present if parameter 
formattedrsn
 is included.
Country
The country that has been set via the TempleOSRS Discord server
Game mode
Enumeration for game mode; 0 = Main, 1 = IM, 2 = UIM, 3 = HCIM
GIM
Enumeration for group iron man mode; 0 = Not GIM, 12 = Regular 2-player, 13 = Regular 3-player, 14 = Regular 4-player, 15 = Regular 5-player, 22 = HC 2-player, 23 = HC 3-player, 24 = HC 4-player, 25 = HC 5-player
fresh_start_account
Bit that marks if the player has been flagged as a fresh start world account
Cb-3
Bit that marks if the player has been flagged as a level 3 account
F2p
Bit that marks if the player has been flagged as a free-to-play account
Disqualified
Bit that marks if the player has been disqualified from the website
Clan preference
Custom requested group ID for the verified or featured clan logo present on player page
Last checked
Timestamp of the last time the player was attempted to be updated
Last changed
Timestamp of the last time the player was updated
Datapoint Cooldown
Time in seconds until the player may be attempted to be updated
collection_log/log_synced
Boolean (1 or 0) whether player has successfully syncronized their collection log. 
collection_log/last_checked
Timestamp of the last time player has syncronized their collection log through the plugin.
collection_log/last_changed
Timestamp of the last time player has syncronized their collection log with a new item through the plugin.

Competition Information V2
GET
                This endpoint attempts to give you any valuable information about a competition
                Participants are listed in rank order, by the skill in which the competition defaults to if no skill is defined
                Example: 
https://templeosrs.com/api/competition_info_v2.php?id=15025
Parameters
Parameter
Documentation
id
The competition ID of the competition, ID is in the URL of the competition's page
skill
Skill parameter name (lowercase) OR number for the desired skill
details
Just including this parameter with any value will add start and end XP/KC values for each player
snapshot
Point in time which you want to view the competition in. For example:
&snapshot=1day
 to view the competition standings after first day 
&snapshot=2week
 to view the competition standings after two weeks
format
Response format. Currently only supported value is 
&format=table
 for easier spreadsheet implementations
altunranked
Alternative way of returning unranked bosses. Boss KCs are instead of being returned as the minimum hiscores threshold, returned as minimum hiscores threshold - 1.

Documentation

The competition ID for confirmation purposes

data/info/team_competition
Bit that marks if the competition was team based
data/info/skill_competition
Bit that marks if the competition is skill based (0 = skill, 1 = boss)
data/info/skill
The default skill for the competition
data/info/skill_index
The default skill's skill enumeration for the competition
data/info/start_date
The starting timestamp for the competition (UTC)
data/info/end_date
The ending timestamp for the competition (UTC)

Current timestamp (UTC)
data/info/start_date_unix
UNIX timestamp for the start date (UTC)
data/info/end_date_unix
UNIX timestamp for the end date (UTC)

UNIX timestamp for current time (UTC)

The linked groups ID if set

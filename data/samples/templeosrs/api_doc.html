Spreadsheet Information
Some of the endpoints have alternative formats that are easier to import into your google spreadsheets if you are having trouble with JSON data.
You only need to copy the provided the links below to your spreadsheets formula bar and it should work.
If you are having any trouble you can always ask for help on our discords #help channel.

Competition Information V2

- Once you have copied the formula below into your spreadsheet you need to change this number id=27764 to match your competitions ID to fetch data from it
- You can change what skill/boss/custom category is being used by adding &skill=prayer at the end of the URL
- And view the competition standings as they were for example after day one by adding this &snapshot=1day to the URL
- If you want the table to return the competition standings for teams change the parameter &format=table to &format=tableTeams
- You can use &format=csv to return the data in a CSV format

Competitive Community Endpoints

Recent 200ms
GET
This endpoint attempts to retrieve a list of the 25 most recent 200ms in a skill

Example: https://templeosrs.com/api/recent_200ms.php?skill=8

Parameters

Parameter Documentation
skill Skill parameter enumeration, goes in order of which the skills are shown on the hiscores page
0 = Overall ... 24 = EHP (119 = Sailing)

Attributes

Attribute Documentation
data/Username The RSN of the player who achieved a 200m
data/Date The timestamp of the data point of which the player achieved a 200m
data/Skill Skill parameter enumeration, goes in order of which the skills are shown on the hiscores page
0 = Overall ... 24 = EHP (119 = Sailing)
data/Country The country of the player that has been set via the TempleOSRS Discord server
data/Game Mode Enumeration for game mode; 0 = Main, 1 = IM, 2 = UIM, 3 = HCIM
data/Twitter The player's Twitter profile link (donation perk)
data/Rank The player's rank for the skill on the official hiscores
Recent Records
GET
This endpoint attempts to retrieve a list of the 10 most recent records in a skill

Example: https://templeosrs.com/api/recent_records.php?skill=24

Parameters

Parameter Documentation
skill Skill parameter enumeration, goes in order of which the skills are shown on the hiscores page
0 = Overall ... 24 = EHP (119 = Sailing)

Attributes

Attribute Documentation
data/player The RSN of the player who achieved a record
data/skill Skill parameter enumeration, goes in order of which the skills are shown on the hiscores page
0 = Overall ... 24 = EHP (119 = Sailing)
data/category Enumeration for record category
0 = 5m, 1 = Day, 2 = Week, 3 = Month, 4 = Year
data/rank Rank of the record in the respective category (only top 3 returned)
data/date The timestamp of the data point of which the player achieved a record
data/xp The xp of the skill in which the player received a record
Top Records
GET
This endpoint attempts to retrieve a list of the top 50 records for each category in a skill

Example: https://templeosrs.com/api/records.php?skill=Mining

Parameters

Parameter Documentation
skill Skill name for the desired skill; this is an outdated endpoint that uses the name of the skill
country Name of country
build Parameter name for account build
gamemode Game mode number
group Group ID number
records Whether to display all records instead of only competitive ones
Accepts only one parameter "all"

Attributes

Attribute Documentation
%CATEGORY%/ The record category in which the next subcategory of information will be part of
Available categories: "Day","Week","Month","6h","Year"
%CATEGORY%/%RANK% The rank, 1 through 50, in the specific record category for the skill
%CATEGORY%/%RANK%/player The RSN of the account who holds the record
%CATEGORY%/%RANK%/nickname The RSN of the account who holds the record, with custom capitalization
%CATEGORY%/%RANK%/xp The xp gained during the time period of the record
%CATEGORY%/%RANK%/date The timestamp of which the record was obtained
%CATEGORY%/%RANK%/country The country of the player that has been set via the TempleOSRS Discord server
%CATEGORY%/%RANK%/icon_url The icon url of the player's donation perk icon
%CATEGORY%/%RANK%/icon_desc The icon description of the player's donation perk icon
%CATEGORY%/%RANK%/game_mode Enumeration for game mode; 0 = Main, 1 = IM, 2 = UIM, 3 = HCIM
%CATEGORY%/%RANK%/video_url The video URL of any proof of skill records captured by the player
This field is mandatory for any 6h records after August 21st 2021

EHP By Rank
GET
This endpoint attempts to retrieve the rank threshold for a specified metric.

Examples: https://templeosrs.com/api/ehp_by_rank.php?rank=1000&metric=im

Parameters

Parameter Documentation
rank The rank that you wish to know the rank threshold value of.
metric The metric which you want to get the rank threshold from.
Accepted Values: ehp, im, uim, f2p, f2pim, f2plvl3, lvl3, ehb, ehbim
Default Value: ehp

Attributes

Attribute Documentation
data/metric Confirmation of the metric parameter.
Returned Values: EHP, IM-EHP, UIM-EHP, F2P-EHP, F2P-IM-EHP, F2P-LVL3-EHP, LVL3-EHP, EHB, IM-EHB
data/rank Confirmation of the rank parameter.
data/rank_threshold The rank threshold for the specified metric and rank, with four digits of precision.

Player Specific Endpoints

Player Information
GET
This endpoint attempts to give you any valuable information from the player's overview page.

Example: https://templeosrs.com/api/player_info.php?player=Mikael

Parameters

Parameter Documentation
player The current RSN of the player you are trying to look up
dateformat Format of the dates returned. Currently only supported value is "unix" for unix timestamp.
cloginfo The response will include additional collection log related information.
formattedrsn The response will include the RSN how it is in-game with proper capitalization and special characters.

Attributes

Attribute Documentation
Username The current RSN of the player
player_name_with_capitalization The RSN of the participant, with special symbols and capitalization it has ingame.
Note: Only present if parameter formattedrsn is included.
Country The country that has been set via the TempleOSRS Discord server
Game mode Enumeration for game mode; 0 = Main, 1 = IM, 2 = UIM, 3 = HCIM
GIM Enumeration for group iron man mode; 0 = Not GIM, 12 = Regular 2-player, 13 = Regular 3-player, 14 = Regular 4-player, 15 = Regular 5-player, 22 = HC 2-player, 23 = HC 3-player, 24 = HC 4-player, 25 = HC 5-player
fresh_start_account Bit that marks if the player has been flagged as a fresh start world account
Cb-3 Bit that marks if the player has been flagged as a level 3 account
F2p Bit that marks if the player has been flagged as a free-to-play account
Disqualified Bit that marks if the player has been disqualified from the website
Clan preference Custom requested group ID for the verified or featured clan logo present on player page
Last checked Timestamp of the last time the player was attempted to be updated
Last changed Timestamp of the last time the player was updated
Datapoint Cooldown Time in seconds until the player may be attempted to be updated
collection_log/log_synced Boolean (1 or 0) whether player has successfully syncronized their collection log.
collection_log/last_checked Timestamp of the last time player has syncronized their collection log through the plugin.
collection_log/last_changed Timestamp of the last time player has syncronized their collection log with a new item through the plugin.

Player Gains
GET
This endpoint attempts to give you recorded player gains from several of the player's pages

Example: https://templeosrs.com/api/player_gains.php?player=FasTLT&time=10000000&bosses=1

Parameters

Parameter Documentation
player The current RSN of the player you are trying to look up
time Number of seconds before the current timestamp to start recording gains from.
This variable has special parameters for time in string format: day, week, month, year, cday, cweek, cmonth and cyear.
Parameters with c-prefix return calendar date. For example cyear returns the current calendar year 2024-01-01 - 2025-01-01
bosses Bit that marks if you want the server to return non-skill gains

Attributes

Attribute Documentation
data/Date The timestamp of the start of the selected gains window
data/Player The RSN of the player
data/Primary_ehp The key for players primary EHP type
data/Primary_ehb The key for players primary EHB type
Note: Only present when boss data is requested
data/%SKILL% The experience recorded on the data point for the selected %SKILL%

data/participants/%RANK%/username The RSN of the participant
